## Delivery and verification

Use scoped DeepSeek V4.1 Flash tasks through OpenCode Go for implementation, followed by independent review. The parent coordinates server-project Vitest: separate concurrent invocations reset the same template database and are prohibited. Package tests, typechecks and disposable SQL smoke tests can run independently.

Audience provenance needs an upgrade migration. Existing rows cannot establish destinations used before the migration; document that limit and surface unresolved cleanup instead of asserting historical erasure succeeded. Destination/connection changes and removal of one platform must preserve cleanup obligations until remote confirmation. Configuration and erasure races need explicit coverage.

Budget checks need deterministic concurrent calls and failure injection around usage persistence. Hosted-run checks need stale takeover followed by late completion, including disabled/paused/revoked agents.

Keep release/version surfaces at 0.7.2 during implementation. The release owner updates them together once scope and migration numbers settle. Full CI and independent review gate merge; the release workflow gates publication. If audience migration scope expands substantially, the five budget/hosted fixes may ship first.
