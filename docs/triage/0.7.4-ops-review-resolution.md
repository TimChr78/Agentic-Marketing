# 0.7.4 operations review corrections

The independent review approved the baseline fixes with two P2 scope gaps and four smaller follow-ups. Corrections before release:

- Resolved episodes and disabled rules now retry the original webhook delivery row in the reconciliation sweep. Both queued and already-failed retryable ledger entries are selected; confirmed delivery still becomes sent.
- Alert test feedback reports sent/queued/failed separately; a queued webhook is never called sent by the UI.
- Re-opening uses an atomic terminal-status predicate and a persistent counter on the delivery row. A concurrent worker's pending/running/done row cannot be reset, and a missing event-ledger entry cannot reset the retry budget. Migration 0073 adds alert_retry_cycles (zero re-opens used by default); only one re-open is allowed, for two total delivery cycles. The existing worker's within-cycle retry schedule is unchanged. Missing delivery payloads are terminal, not a promise of an impossible retry.
- The enrollment regression now executes the chunk inside a real transaction and throws after its writes, before commit. It checks participant count as well as cursor/count preservation and subsequent completion without duplicate enrollment.
- The provisional 0073 → 0.7.4 migration mapping remains parent-owned bookkeeping. It will ship with the final version bump; it records the actual new migration head for backups, including if migrations run before server startup.

Relevant alerts/server/web typechecks pass. Final package/web and coordinated server gates plus independent delta review are pending at this checkpoint. The earlier 24-case server gate and full CI passed before these corrections. No issue closes or merge occurs until the new gates pass.

User-visible behavior: webhook acceptance is queued, completion is sent, terminal exhaustion is failed. After one extra outbox cycle, unavailable endpoints stay failed without endless retries. Payload, endpoint and idempotency key are reused; no new webhook event is invented for a resolved alert.
