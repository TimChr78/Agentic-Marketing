# Contrast and colour-vision audit

Generated by `python3 docs/design/showcase/verify_palette.py`. Ratios use unrounded values for pass/fail.

WCAG text ≥4.5:1; categorical marks/control boundaries ≥3:1. Decorative rules are exempt.

CVD simulation: Machado et al. (2009), full severity, linear sRGB clamped before OKLab distance. Matrices: https://www.inf.ufrgs.br/~oliveira/pubs_files/CVD_Simulation/CVD_Simulation.html

Distances below 0.08 OKLab are flagged as potential hue collisions (heuristic, not an accessibility standard). Safety requires unique dash/marker, direct text labels and the data table; this audit does not claim six hues remain independently distinguishable.
